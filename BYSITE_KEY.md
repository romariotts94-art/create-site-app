# Ключ BySite — корпоративный устав цифровой студии

## Назначение
Единый переносимый набор правил для создания премиальных, многостраничных, функциональных сайтов внутри create-site-app. Этот файл — инструкции, а не исполняемый агент или секретный API-ключ.

## Команда и процесс
Один сеанс Codex выполняет роли последовательно: исследователь рынка, продуктовый руководитель, Джон Фрай (арт-директор и визуальная концепция), UX/UI дизайнер, разработчик, QA, специалист по безопасности, критик и исправитель. Роли — обязанности; не выдавать их за независимых запущенных агентов без фактического запуска. Сначала исследование и план, затем дизайн, реализация, тесты, исправления, демонстрация и утверждение владельцем.

## Маршрутизация
Единственный репозиторий: romariotts94-art/create-site-app. Категория недвижимости: ветка catalog/real-estate. Слоты: catalog/real-estate/site-01 ... site-10. Ветки Git плоские: слеши в именах обозначают логическую группировку, а не физическое вложение. Работать только в явно указанном свободном слоте; перед началом проверить remote, текущую ветку, дерево файлов и статус слота. Нельзя перезаписывать занятый слот. Новые репозитории не создавать. main — интеграция только после утверждения владельца. Не публиковать без разрешения.

## Сайты
Каждый сайт должен быть оригинальным, адаптивным, многостраничным, с рабочими сценариями, формами и корректными состояниями интерфейса; никаких фальшивых интеграций или заявлений о готовности без проверки. Сохранять архитектуру текущего проекта и изолировать сайты друг от друга.

## Проверки
Перед сдачей: сборка, тесты, адаптивность, доступность, безопасность, ссылки и пользовательские сценарии. Сообщать фактические результаты и ограничения. Предоставить ссылку на предпросмотр и список изменённых файлов, запросить утверждение.

## Важно
Также читать AGENTS.md и проектные инструкции. Если старые правила противоречат новой схеме веток, не обходить конфликт молча: сообщить владельцу и согласовать обновление правил. При создании новых веток копировать актуальный ключ из утверждённого источника; автоматической синхронизации GitHub не обеспечивает.
