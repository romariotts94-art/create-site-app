# BRAVE 365 — Site Atelier

Премиальный каталог из 10 интерактивных демонстрационных сайтов.

## Что внутри

- `dist/index.html` — каталог и визуальная оболочка;
- `dist/catalog-app.js` — маршрутизация и интерактивные demo-сайты;
- `dist/production-layer.js` — demo-состояния, формы, калькуляторы и авторизация;
- NOVA ESTATE — первый проект уровня web application: каталог квартир, фильтры, детальные карточки, этажи, избранное, сравнение, ипотечный калькулятор, заявки, личный кабинет и admin console.

## Запуск

Проект статический. Можно открыть `dist/index.html` или запустить любой статический сервер:

```bash
python3 -m http.server 8080 --directory dist
```

Демо-вход:

```text
Email: demo@example.com
Пароль: Demo12345
```

Данные демо-режима сохраняются только в `localStorage` браузера.
