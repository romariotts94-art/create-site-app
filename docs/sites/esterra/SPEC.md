# ESTERRA — запуск 1 / фундамент и вертикальный срез

## Цель

ESTERRA — отдельный продаваемый продукт внутри каталога `create-site-app`: российский marketplace недвижимости для покупки, долгосрочной аренды и посуточной аренды.

## Аудитория и роли

- Клиент: ищет объект, открывает карточку, отправляет заявку.
- Оператор: получает заявку из `inquiries` для дальнейшей обработки.
- Администратор: следующий этап; в запуске 1 доступ к операционным действиям не добавляется.

## P0 первого запуска

1. Рабочий каталог ESTERRA виден в существующем каталоге BRAVE 365.
2. Серверная БД хранит объекты и заявки.
3. Поиск фильтрует по типу сделки, тексту, цене и комнатам.
4. Карточка объекта показывает реальные поля из API.
5. Заявка проходит клиентскую и серверную валидацию и сохраняется в SQLite.
6. Ошибка API не маскируется успешным состоянием.

## Границы

В этом запуске нет аккаунтов, ролей, платежей, бронирования, загрузки изображений и production-развёртывания отдельного API. Эти функции не имитируются. Внешние изображения Unsplash используются как визуальные seed-материалы и должны быть заменены/лицензированы заказчиком перед коммерческой передачей.

## Локальный запуск

```text
node sites/esterra/server.mjs
```

Открыть `http://127.0.0.1:4175/esterra/`. API: `/api/esterra/health`, `/api/esterra/properties`, `/api/esterra/inquiries`.
